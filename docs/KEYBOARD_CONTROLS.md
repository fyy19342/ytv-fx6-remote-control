# キーボード操作 — 20261001c

ログイン後、FX6 Operation App の操作画面にフォーカスがあり、カメラ接続状態を確認できている間だけ有効です。ログイン入力欄、別アプリ、別ウィンドウ、モーダルダイアログ、切断状態ではカメラを操作しません。

| モード選択 | u: 1段明るく | d: 1段暗く | SDK |
| --- | --- | --- | --- |
| i: Iris | 小さい F 値 | 大きい F 値 | FNumber |
| g: Gain (ISO) | 大きい ISO | 小さい ISO | IsoSensitivity |
| n: ND | 小さい分母／小さい光学濃度 | 大きい分母／大きい光学濃度 | NDFilterOpticalDensityValue |

b は全モードで ND ON + 有効な最小濃度、m は ND OFF。どちらも選択モードを維持します。前回濃度への復帰は行いません。ND OFF 中の n → u/d は GUI と backend の両方で拒否します。値は SDK が返す有効なリストを数値順に処理し、端で止まります。並びが不規則でも取得順に依存しません。

修飾キーなしで入力し、英字入力を使用してください。キー長押しの自動反復は無効です。未選択時の u/d は説明を表示します。操作結果とエラーは画面下部に表示されます。

Gain (ISO) は dB ゲインや Base ISO HIGH/LOW とは異なる ISO sensitivity です。ISO AUTO と不明値は数値の段階操作から除外します。Iris が CLOSE の場合は u で最大 F 値へ戻れます。SDK の FNumber は実 F 値の100倍です。

ND 表示は `1/~4 (OD 0.6)` のように分母目安と光学濃度を併記します。分母は `10^(raw/100)` を丸めた目安で、カメラ表記の 1/128 などと完全一致しない場合があります。

ND ON の途中失敗は OFF を要求し、OFF 読み戻し成功／失敗を明示します。OFF への復帰に失敗した場合は実機状態を直ちに確認してください。Manual/Step 設定は残る場合があります。実機未接続時のテストでは光学変化は検証できません。
