# キーボード操作 — 20261002f

ログイン後、FX6 Operation App の操作画面にフォーカスがあり、カメラ接続状態を確認できている間だけ有効です。ログイン入力欄、別アプリ、別ウィンドウ、モーダルダイアログ、切断状態ではカメラを操作しません。

操作画面の4枚のカードにモード選択キーを表示します。U/D・ND・AWB の簡易説明は常時表示し、詳しい手順は「キー操作」ボタンで開閉できます。説明の開閉で操作モードやカメラ設定は変わりません。

| モード選択 | u: 1段明るく | d: 1段暗く | SDK |
| --- | --- | --- | --- |
| i: Iris | 小さい F 値 | 大きい F 値 | FNumber |
| g: Gain (ISO) | 大きい ISO | 小さい ISO | IsoSensitivity |
| n: ND | 小さい分母 | 大きい分母 | NDFilterValue（透過率） |
| s: Shutter Speed | 遅くする（露光時間を長く） | 速くする（露光時間を短く） | ShutterSpeedValue |

b は全モードで ND ON/OFF を切り替えます。カメラから現在状態を読んで判定し、OFF → ON では有効な最小濃度へ設定、ON → OFF では OFF にします。状態不明時には推測して切り替えません。m は ND OFF 専用です。どちらも選択モードを維持します。前回濃度への復帰は行いません。ND OFF 中の n → u/d は GUI と backend の両方で拒否します。値は SDK が返す有効なリストを数値順に処理し、端で止まります。並びが不規則でも取得順に依存しません。

修飾キーなしで入力し、英字入力を使用してください。キー長押しの自動反復は無効です。未選択時の u/d は説明を表示します。操作結果とエラーは画面下部に表示されます。

Gain (ISO) は dB ゲインや Base ISO HIGH/LOW とは異なる ISO sensitivity です。ISO AUTO と不明値は数値の段階操作から除外します。Iris が CLOSE の場合は u で最大 F 値へ戻れます。SDK の FNumber は実 F 値の100倍です。

ND 表示は `1/4`、`1/5` のように SDK の透過率を使います。上位32bitの分子・下位32bitの分母を解釈し、候補値の明るい順で1段ずつ変更します。光学濃度を丸めた近似値で制御しません。

ND ON の途中失敗は OFF を要求し、OFF 読み戻し成功／失敗を明示します。OFF への復帰に失敗した場合は実機状態を直ちに確認してください。Manual/Variable 設定は残る場合があります。実機未接続時のテストでは光学変化は検証できません。

FX6 の ND は SDK の透過率リストを使用します。たとえば 1/4 → 1/5 のように、実機の候補値の隣へ移動します。操作時は対応する Variable / Manual へ切り替え、OFF 中の u/d では設定変更しません。

S は操作対象の選択だけを行い、カメラの設定を変えません。その後の U/D で、対応する手動 Speed モードへ切り替えて1段調整します。速度は分数の露光時間で比較し、SDK の元データで設定します。OFF / Auto / Angle / ECS の状態は速度として誤表示せず、そのモード名を表示します。手動 Speed 設定は操作後も残ります。モード変更や速度設定を確認できない場合は失敗を表示し、状態を再取得します。

## A: 1回の Auto White Balance

A を押すと AWB を1回実行し、選択中の Iris / Gain (ISO) / ND / Shutter Speed モードは維持します。測定値を固定するため、ATW の場合は Manual に切り替えてから AWB を押下・解放します。実行後も Manual を維持します。

カメラ本体の WHT BAL をメモリー A または B にしてください。本体の WB メモリー A とキーボードの A キーは別です。被写体と同じ照明の白い紙などを画面内に大きく映し、適切な明るさにして実行します。カメラ本体の PRESET や撮影条件によっては実行できません。手順の根拠は [Sony FX6 取扱説明書 p.51](https://pro.sony/support/res/manuals/5024/c3bfbc891ee0f149e46d142754fd6aa7/50244581M.pdf#page=51) です。

GUI の White Balance 行に色温度、Manual / ATW、AWB の状態を表示します。SDK が指示を受け付けた時点は「結果確認中」で、成功通知を受けたときに「完了」とします。明るさ不足などの失敗を通知された場合は理由を表示します。15秒間結果通知がない場合や確認前に切断された場合は「結果未確認」です。色温度が変化しただけでは成功扱いにしません。A の再入力は前回の実行から3秒間だけ無効です。結果確認中でも3秒後には再実行できます。完了／失敗通知が3秒以内に届いても、この待ち時間は短くしません。キー長押しの自動反復は無効です。

前の結果が未確認のまま再実行した場合は、取り違えを防ぐため「結果はカメラ本体で確認してください」と表示します。接続をやり直すまでは、通知だけでどの回の測定が成功したかを断定しません。

AWB の押下に失敗した場合にも解放を試みます。解放失敗は明示し、カメラ本体の状態を確認するよう表示します。ホワイトバランス値や測定前の Manual/ATW 設定への自動復帰は行いません。
